# 🤖 بوت إشارات OTC - فوركس

بوت تليجرام متكامل لتوليد ونشر إشارات التداول على أزواج الفوركس OTC (خارج البورصة) باستخدام منصة Pocket Option.

## ✨ المميزات
- عرض رصيد الحساب التجريبي
- اختيار العملة من 5 أزواج فوركس OTC
- اختيار فريم الشمعة (1m, 5m, 15m, 1h)
- اختيار مدة الصفقة (60, 120, 300 ثانية)
- إشارة فورية مع نسبة ثقة وسعر حقيقي
- تعيين قناة النشر التلقائي
- تشغيل النشر التلقائي للإشارات

## 🛠️ المتطلبات
- Python 3.8+
- مكتبات:
  - `pocketoptionapi2`
  - `python-telegram-bot`
