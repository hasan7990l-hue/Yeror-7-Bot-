# 🤖 بوت التنزيل (TikTok Downloader Bot)

بوت تليجرام متطور ومخصص لتنزيل مقاطع الفيديو من تيك توك بجودتها الأصلية وبدون علامات مائية، مع نظام تحكم كامل للمطور.

## 🛠 المميزات
* **تحميل فائق السرعة:** يعتمد على مكتبة `yt-dlp` المحدثة.
* **بدون حقوق:** تحميل الفيديوهات بدون العلامة المائية الخاصة بتيك توك.
* **نظام الاشتراك الإجباري:** حماية لقنواتك عبر نظام الاشتراك الإجباري (حتى 4 قنوات).
* **لوحة تحكم إدارية:** تحكم كامل في الميديا، الإحصائيات، وقنوات الاشتراك عبر أزرار تفاعلية داخل البوت.
* **دعم اللغات:** يدعم العربية والإنجليزية.
* **استقرار عالٍ:** مزود بنظام Web Server مدمج لضمان عمل البوت 24/7.

## 🚀 كيفية التشغيل
1. قم بإنشاء بوت جديد عبر [@BotFather](https://t.me/botfather).
2. احصل على `API_ID` و `API_HASH` من [my.telegram.org](https://my.telegram.org).
3. قم بتعديل ملف البوت ووضع التوكن والمعلومات الخاصة بك.
4. ثبت المكتبات المطلوبة:
